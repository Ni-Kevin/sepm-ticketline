How to use the hall layout editor
  1. Click inside the hall canvas to create a new area.
  2. Select an area to rename it, change its type, set its color, or update the standing capacity.
  3. Drag an area to move it and use the bottom-right handle to resize it.
  4. Use Seating for seats, Standing for open audience zones, and Stage for the performance area.
  5. When you assign an area to Seating, the editor automatically fills the entire area with seats.
  6. If you enlarge a seating area later, new seats are not added automatically. Existing seats stay, and seats outside the resized area are removed.
  7. If you want the whole seating area to be filled again, reassign the area type to Seating.
  8. When a seating area is selected, you can also use the seat grid below to add or remove individual seats manually.
  9. Save the layout after your changes are complete.
